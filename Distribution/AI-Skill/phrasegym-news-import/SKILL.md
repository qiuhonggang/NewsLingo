# NewsLingo 双语新闻学习包

1. 优先取材自路透社、美联社、有具名记者的主流科技媒体，以及 AI 厂商的官网新闻室、产品博客、模型卡或研究发布页。也可用厂商、研究机构的官方 X 帖文等一手发布。点开具体帖文，通过官网指向的账号链接或官网同步发布核实归属。用原始报道或一手发布页作为学习包来源；转载通讯社原稿时保留通讯社署名。聚合简报和转帖仅用来找线索。
2. 打开原文核实标题、发布者、发布时间和正文。媒体报道有对应公告、模型卡或论文时，交叉核对上线范围、数字及限制；只有官方帖文时，在信息足够核实并支撑正文与考题的情况下采用。按用户要求的日期和时区筛选，未限定日期时默认最近七天。跨时区的报道保留原文发布日期，在导读里注明本地日期。区分已发生的事件和预告；找不到足量可核实的新闻就如实说明。
3. 写英文新闻导读。首段直陈谁在何时发布了什么。按读者能理解的顺序组织来自报道的具体事实，保留产品名、数值、适用范围、限制和消息归因。测试指标写清是谁测的。B1 难度应靠较短的句子和清晰的连接降低阅读负担，保留必要技术词。删掉脱离来源的推测、宣传口号、通用背景和模板式结语。篇幅服务于事实，通常 180–350 词。
4. 正文定稿后，理解整个段落再翻成自然简体中文。按原文顺序建立句对，中文动词、数字、否定和适用范围逐一核对。段落字段从同段句对拼合，逐句版使用同一译文。AI 只负责组织与翻译，新闻事实来自所列来源。
5. 编写 4–6 道英文单选题，至少各一题考主旨、细节和推断。每题只有一个能由正文支持的正确答案，解析用简体中文。证据从学习包英文正文原样摘取。生成后重答题目，核查每条证据及关键数字。
6. 按 [双语 v2 格式](references/format.md) 生成学习包。在装有 NewsLingo 的 Mac 上用 `--validate` 验证。用户要求直接导入时，校验成功后执行 `open`，并确认资料库显示了该文章。其他情况交付文件。
